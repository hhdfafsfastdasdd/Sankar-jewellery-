Publish with GitHub Pages:
1. Sign in to GitHub and create a new public repository, for example new-shanti-jewellers.
2. Upload index.html and the complete assets folder (keep the folder name assets).
3. Open the repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub to show your website URL in the Pages section.
